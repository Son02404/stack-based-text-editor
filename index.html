⚙ How It Works

Follow the steps to understand the stack algorithm.

1
A user edits the text

The previous text state is pushed onto the Undo Stack.

2
The user selects Undo

The current state is saved to the Redo Stack, and the most recent previous state is popped from the Undo Stack.

3
The user selects Redo

The most recent undone state is restored from the Redo Stack.

4
A new edit is made after Undo

The Redo Stack is cleared because the previous redo history no longer represents the new editing sequence.
